# Chinese Checkers

Desktop game of Chinese Checkers using Python and Tkinter.

This project mainly concentrates on the integration of Chinese Checkers Board along with responsive UI and animation.

## Features

- Interactive Chinese Checkers Board
- Human vs Computer mode
- Window resizeability
- Maximised window functionality
- Animation of moving marbles
- Hover effects for playables pieces and spaces
- Highlighting of valid moves
- Turn notification
- Celebration upon winning the game
- Rules/Instructions screen
- Dark themed game interface
- Procedural creation of board and marble designs
- No need for any third-party python package

## Tech Stack

- Python 3
- Tkinter
- Rendering with Canvas
- Standard python library
